# Landing sequence

| Film | Action |
| --- | --- |
| AI chat | A prompt asks Kainbu to rename a card. The sent message, response, and renamed board card appear in sequence. |
| Manual | A card title enters inline edit mode, changes, then moves from To do to In progress. |
| Notes | The Kainbu page gains a Next step heading and a mobile-review note. |
| Agent | A terminal agent reads the repo-local Kainbu skill, lists tasks, edits the page, runs a check, and updates a task through the CLI. |

The four films sit in separate landing sections. Motion is restrained so the changed state remains readable before each loop.
